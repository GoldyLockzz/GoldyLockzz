# Hi, I'm Hansel 👋

I build data stuff that is actually meant to solve a problem.

Most of my work sits somewhere between analytics, machine learning and applied AI — usually with messy data, ambiguous business rules, and fewer clean assumptions than expected.

I care about:
- getting useful signal out of ugly data
- building decision systems people can actually use
- testing whether models are genuinely useful instead of just flexing metrics/ visuals
- figuring out where LLMs help, vs where they’re just expensive inference
